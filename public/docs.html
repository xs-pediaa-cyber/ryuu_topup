Api Profile

GET https://xs-pedia.my.id/h2h/profile

Profil

curl -X GET "https://xs-pedia.my.id/h2h/profile" \ -H "X-APIKEY: your_api_key_here"

Api Deposit

GET https://xs-pedia.my.id/h2h/deposit/create

Buat Deposit

Membuat transaksi deposit baru dengan jumlah dan metode pembayaran yang ditentukan.

Parameter Kueri

Parameter Tipe Wajib Deskripsi
nominal integer Wajib
Contoh Permintaan
curl -X GET "https://xs-pedia.my.id/h2h/deposit/create?nominal=25000&metode=QRISFAST" \ -H "X-APIKEY: your_api_key_here"
Contoh Permintaan
const params = new URLSearchParams({ nominal: '25000', metode: 'QRISFAST' }); const response = await fetch(`https://xs-pedia.my.id/h2h/deposit/create?${params}`, { method: 'GET', headers: { 'X-APIKEY': 'your_api_key_here', 'Content-Type': 'application/json' } }); const data = await response.json(); console.log(data);
Contoh Permintaan
import requests url = "https://xs-pedia.my.id/h2h/deposit/create" params = { "nominal": "25000", "metode": "QRISFAST" } headers = { "X-APIKEY": "your_api_key_here", "Content-Type": "application/json" } response = requests.get(url, params=params, headers=headers) data = response.json() print(data)

GET https://xs-pedia.my.id/h2h/deposit/status

Cek Status Deposit

Memeriksa status terkini dari transaksi deposit menggunakan ID deposit.

Parameter Kueri

Parameter Tipe Wajib Deskripsi
id string Wajib ID deposit
Contoh Permintaan
curl -X GET "https://xs-pedia.my.id/h2h/deposit/status?id=ID_TRX_DEPO" \ -H "X-APIKEY: your_api_key_here"
Contoh Permintaan
const params = new URLSearchParams({ id: 'ID_TRX_DEPO' }); const response = await fetch(`https://xs-pedia.my.id/h2h/deposit/status?${params}`, { method: 'GET', headers: { 'X-APIKEY': 'your_api_key_here', 'Content-Type': 'application/json' } }); const data = await response.json(); console.log(data);
Contoh Permintaan
import requests url = "https://xs-pedia.my.id/h2h/deposit/status" params = { "id": "ID_TRX_DEPO" } headers = { "X-APIKEY": "your_api_key_here", "Content-Type": "application/json" } response = requests.get(url, params=params, headers=headers) data = response.json() print(data)

Respons

200 OK
200 OK
{ "success": true, "data": { "id": "ID_TRX_DEPO", "status": "success", "nominal": 2000, "fee": 2, "get_balance": 1998 } }
GET https://xs-pedia.my.id/h2h/deposit/cancel

Batalkan Deposit

Membatalkan transaksi deposit yang tertunda menggunakan ID deposit.

Parameter Kueri

Parameter Tipe Wajib Deskripsi
id string Wajib ID transaksi deposit untuk dibatalkan
Contoh Permintaan
curl -X GET "https://xs-pedia.my.id/h2h/deposit/cancel?id=ID_TRX_DEPO" \ -H "X-APIKEY: your_api_key_here"
Contoh Permintaan
const params = new URLSearchParams({ id: 'ID_TRX_DEPO' }); const response = await fetch(`https://xs-pedia.my.id/h2h/deposit/cancel?${params}`, { method: 'GET', headers: { 'X-APIKEY': 'your_api_key_here', 'Content-Type': 'application/json' } }); const data = await response.json(); console.log(data);
Contoh Permintaan
import requests url = "https://xs-pedia.my.id/h2h/deposit/cancel" params = { "id": "ID_TRX_DEPO" } headers = { "X-APIKEY": "your_api_key_here", "Content-Type": "application/json" } response = requests.get(url, params=params, headers=headers) data = response.json() print(data)

Respons

200 OK
200 OK
{ "status": "success", "message": "Transaction cancelled successfully", "data": { "trx_id": "lD_TRX_DEPO", "new_status": "CANCELLED" } }
